# צחצוח או כלום 🪥

שעון מעורר לאייפון שנכבה רק אחרי שמצלמים את עצמך מול המראה עם מברשת שיניים בפה.
חינמי לגמרי: הכול רץ על המכשיר, בלי שרת ובלי מפתח API.

## איך זה עובד

- **צלצול אמיתי** (AlarmKit, iOS 26): עובד גם במצב שקט ובמסך נעול.
- **אין בריחה**: לחיצה על "עצור" מחזירה את הצלצול בעוד 2 דקות, וזה ממשיך עד שמצלמים הוכחה.
- **הבדיקה** (Vision של אפל): יש פנים בתמונה, ויש יד ליד הפה.
- **רק מצלמה חיה**: אין גישה לגלריה.

## הרצה

צריך Mac עם Xcode 26 ואייפון עם iOS 26.

```bash
brew install xcodegen
cd ios/BrushAlarm
xcodegen generate
open BrushAlarm.xcodeproj
```

ב-Xcode בוחרים Team (אפשר Apple ID חינמי) תחת Signing & Capabilities, ומריצים על האייפון.
