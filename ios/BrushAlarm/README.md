# צחצוח או כלום 🪥

שעון מעורר לאייפון שנכבה רק אחרי שמצלמים את עצמך מול המראה, עם מברשת שיניים בפה ושיער רטוב.

## איך זה עובד

1. **AlarmKit (iOS 26)**: צלצול אמיתי של מערכת. עובד גם במצב שקט, במסך נעול ובמצב "ריכוז".
2. **אין דרך לברוח**: לחיצה על "עצור" מפעילה את `RingAgainIntent`, שקובע צלצול חדש בעוד 2 דקות (אפשר לשנות בהגדרות). כך זה ממשיך עד שמגיעה הוכחה.
3. **"צלם הוכחה"** פותח את האפליקציה ישר על המצלמה, ונותן 3 דקות לצלם לפני הצלצול הבא.
4. **הבדיקה**:
   - **על המכשיר** (Vision): יש פנים בתמונה? אם לא, התמונה נדחית מיד בלי לפנות ל-API.
   - **Claude Vision**: בודק כל קריטריון בנפרד: פנים, מראה, מברשת *בפה*, שיער רטוב, ושזו תמונה אמיתית ולא צילום של מסך. האפליקציה מחשבת בעצמה שכל הבדיקות עברו, ולא סומכת על דגל "עבר" אחד.
5. **אין גלריה**: רק מצלמה חיה, אז אי אפשר להשתמש בתמונה של אתמול.

## הרצה

צריך Mac עם Xcode 26 ואייפון עם iOS 26 ומעלה.

```bash
brew install xcodegen
cd ios/BrushAlarm
xcodegen generate
open BrushAlarm.xcodeproj
```

ב-Xcode: בוחרים Team תחת Signing & Capabilities, מחברים את האייפון ומריצים.
באפליקציה: מדביקים מפתח API מ-console.anthropic.com, קובעים שעה ומפעילים.

## מבנה

| קובץ | תפקיד |
|---|---|
| `Alarm/AlarmController.swift` | תזמון AlarmKit ושרשרת הצלצולים החוזרים |
| `Alarm/AlarmIntents.swift` | מה קורה בלחיצה על "עצור" או "צלם" |
| `Verification/PhotoVerifier.swift` | Vision + קריאה ל-Claude עם JSON schema |
| `Verification/CameraPicker.swift` | מצלמה חיה בלבד |
| `Views/` | מסך הגדרות ומסך אימות |
| `Storage/` | הגדרות (UserDefaults) ומפתח API (Keychain) |

## הערות

- כל בדיקה עולה בערך סנט או שניים. המודל הוא `claude-opus-5-5` עם `effort: low`, כדי שהבדיקה תהיה מהירה בבוקר.
- המפתח שמור ב-Keychain של המכשיר בלבד. אם מפיצים את האפליקציה לאחרים, עדיף להעביר את הקריאה דרך שרת קטן ולא לשים מפתח באפליקציה.
